# Cold Chain — consumer app

**Point of view.** Trust is the conversion lever in a market that reads inspection headlines weekly, so the interface looks like the operations system behind the food: timestamped, exact, updated in front of you. Every bag shows when it was listed, when the window closes, and who attested to the handling.

**How it differs.** No hero imagery at all in browse — data rows with a four-field footer (listed / closes / left / countdown). IBM Plex Sans with Plex Mono for every number, 10px radii, hairline borders, 140ms precise easing, a live "updated 21:06" stamp in the header, and a chain-of-custody timeline on bag detail.

**Keeping it from going clinical.** One warm accent (orange) is reserved exclusively for price and savings, ratings stay human, and the copy is plain-spoken rather than procedural.
