Primary action control; one `primary` per screen (Reserve / Pay / Redeem).

```jsx
<Button variant="primary" size="lg" fullWidth iconEnd="arrow-right">Reserve for KD 2.000</Button>
```

Variants: primary, secondary, ghost, deal (price-forward CTA), danger. Sizes sm/md/lg map to 32/44/52px — never go below md for a real touch target.
